Backend selection
-----------------
1. Read an existing per-extraction selected-path cache, if present.
2. Otherwise run 5.27.00.0003 with the read-only /SM argument while capturing
   combined stdout/stderr with a 30-second timeout.
3. Accept only output containing (/SM), System manufacture, and Done.
4. Reject known failure text, start failures, crashes, and timeouts.
5. If rejected, probe 5.20.0042 with the same rules.
6. Save one selected executable path and forward all existing downstream
   AMIDEWIN arguments to it. No per-command fallback is performed.
7. If neither candidate passes, return ERROR_NOT_SUPPORTED and log that no
   compatible SMBIOS backend is available.
